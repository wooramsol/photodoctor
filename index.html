민감한 자료를 다루는 일이기에 처음부터 끝까지 흔적을 남기지 않는 방식으로 운영합니다.

  • 가입·이름·연락처 없이 익명 채팅 상담
  • 최종 전달 직후 원본·결과물·대화 기록 삭제, 서버 보관 없음

하지 않는 작업 — 공문서 위·변조, 타인의 초상권·저작권을 침해하는 합성은 진행하지 않습니다. 작업물의 사용 책임은 의뢰인에게 있습니다.

파일 보내고, 견적 확인하고, 이체하면 끝

    채널톡으로 수정할 이미지와 내용을 정확히 표시해서 보내주세요.

  2. 견적 · 작업시간 안내

    평균 1시간 내 답변합니다. 이미지를 보낸 순으로 답장하니 이미지를 꼭 먼저 보내주세요.

  3. 계좌이체

    안내드리는 계좌로 이체하시면 입금 확인 즉시 작업을 시작합니다.

  4. 결과물 전달 · 수정

    원본과 같은 형식으로 전달하고, 의뢰 범위 안의 수정 요청을 반영합니다.

  5. 파일 전부 삭제

    최종 전달이 끝나면 원본, 결과물, 대화 기록을 삭제합니다.

자주 묻는 질문

① 채널톡 익명 상담·접수 → ② 계좌이체(입금 확인 후 작업 시작) → ③ 작업 진행 → ④ 결과물 전달 → ⑤ 최초 의뢰 범위 안에서 수정 → ⑥ 수정본 전달 후 원본·결과물·상담 기록 즉시 삭제. 이 순서로 진행됩니다.
단순 수정은 당일~1일, 정밀 합성이나 복원은 며칠이 걸릴 수 있습니다. 상담 때 예상 소요 시간을 먼저 알려드립니다.
꼭 원본 파일(촬영 원본, 스캔 원본, PDF 원본)을 보내주세요. 화질이 좋을수록 결과가 자연스럽습니다. 캡처본도 가능하지만 원본이 있다면 원본을 권장합니다.
채널톡 상담에서 견적을 확인한 뒤 계좌이체로 진행합니다. 입금이 확인되면 작업을 시작합니다. 카드 결제는 지원하지 않습니다.
네. 익명으로 상담할 수 있고, 모든 작업물은 최종 전달 후 즉시 삭제됩니다. 상담자의 기록 정보 또한 안전하게 삭제됩니다. 제작된 작업물은 포트폴리오로 사용될 수 있는데, 원하지 않으시면 상담 때 [포트폴리오 사용 비희망]이라고 남겨주세요. 어디에도 게시하지 않습니다.
네. 최초 의뢰 범위 안의 수정은 반영해 다시 보내드립니다. 다만 상담 시 요청하지 않은 부분은 합성에 반영되지 않으며, 최초 의뢰 내용과 다르거나 작업 진행 중 수정을 요청하시면 추가 비용이 청구될 수 있습니다.
있습니다. 제3자의 저작권·초상권을 침해하는 작업과 공문서 위조는 하지 않습니다. 제작되는 작업물은 저작권 문제가 없는 저작물이며, 작업물의 불법적인 사용이나 이후 발생하는 법적 문제에 대한 책임은 의뢰자에게 있습니다. 법적 관련 문제는 꼭 확인해 주세요.
